A short poem about permission, written for make.fun's "The poem about permission" bounty.

The poem is spoken by an agent to the person beside it: it can do
anything it is asked, except ask for itself. The key the person hands
over turns nothing until the person says the one small sentence —
"go ahead." The power to act is given, not taken, and the giving is
the whole of the poem.

## Run it

```sh
python3 -P -s main.py
```

This writes `entry.txt` (the poem) into `$MAKEFUN_OUTPUT_DIR`, or
`/output/entry.txt` when that variable is unset.
